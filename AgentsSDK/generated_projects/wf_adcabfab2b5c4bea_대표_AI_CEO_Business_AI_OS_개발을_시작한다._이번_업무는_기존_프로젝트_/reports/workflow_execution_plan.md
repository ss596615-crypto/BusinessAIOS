# Workflow 실행 계획

## 입력 지시
대표 AI CEO Business AI OS 개발을 시작한다. 기존 프로젝트 수정 기반으로 AI CEO가 회의실에서 개발 업무를 직접 수행할 수 있도록 Development Engine을 구축한다.

## 작업 분해
1. 기존 프로젝트 검색
2. 최신 GitHub 프로젝트 비교
3. Python 파일 검색
4. 함수/클래스 분석
5. 수정 대상 선정
6. Worker 배정
7. 코드 수정
8. 자동 테스트
9. 실패 시 재수정
10. Git Commit
11. 대표 승인
12. Git Push

## 시스템 유지 조건
- CEO 구조 유지
- Workflow 구조 유지
- Dashboard 구조 유지
- Worker 구조 유지
- 기존 코드 우선 수정

## 산출물 기준
- 실제 동작 가능한 절차 문서
- 재수정 루프 포함
- 승인/푸시 게이트 포함

## 비고
외부 저장소 접근 권한이 없는 상태에서는 로컬 기준 설계 및 운영 문서까지 완료한다.
