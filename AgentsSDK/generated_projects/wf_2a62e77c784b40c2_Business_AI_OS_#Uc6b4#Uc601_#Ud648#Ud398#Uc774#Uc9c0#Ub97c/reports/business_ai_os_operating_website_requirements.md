# Business AI OS 운영 홈페이지 구축 요구정리

## 1. 프로젝트 목표
- Business AI OS 운영 홈페이지를 구축하고 출시한다.

## 2. 업무 범위
### 반드시 포함할 기능
- 서비스 소개/브랜드 소개
- 핵심 기능 요약
- 운영 현황 또는 공지 섹션
- 문의/연락 CTA
- 반응형 기본 레이아웃

### 제외 범위
- 로그인/회원가입
- 관리자 대시보드
- 결제/구독 기능
- 복잡한 백오피스 연동
- 외부 API 통합(별도 지시 전까지)

## 3. 재사용 가능한 회사 자산
현재 대화에서 확인 가능한 기존 자산은 제한적이다.
- 프로젝트명: Business AI OS 운영 홈페이지를 구축하고 출시하라.
- 회사 메모리: 운영홈페이지 총괄 지점장 및 3역할 분업 원칙
- 업무 분배 기준: 기존자산·요구정리 / 구축 / 출시검수·배포확인

## 4. 부족한 항목
- 기존 홈페이지 소스 코드
- 디자인 가이드 또는 브랜드 컬러/로고
- 도메인/호스팅 정보
- 배포 계정 정보
- 실서비스용 문구/이미지 자산

## 5. 권한 필요 여부
다음 항목은 외부 권한이 있어야 실제 출시까지 진행 가능하다.
- GitHub 저장소 접근
- 배포 플랫폼 접근(Vercel/Netlify/서버 등)
- 도메인 관리 콘솔 접근
- 디자인/문서 저장소 접근(Google Drive 등)

## 6. 권장 구축 산출물
- index.html
- assets/style.css
- assets/app.js
- deploy-checklist.md

## 7. 다음 실행 제안
1. 기존 홈페이지 자산 검색
2. 구축 담당에게 전달할 최종 요구사항 확정
3. 소스 생성
4. 배포 권한 확인 후 출시 검수 진행
